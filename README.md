# 📡 Eye Radar — Autonomous Air Situational Awareness System

Автономний комплекс моніторингу повітряної обстановки України для цивільної безпеки, що об'єднує Telegram-бота, інтерактивну мапу Telegram Mini App (TMA) та ядро злиття відкритих даних (Data Fusion Core).

---

## 🚀 Основні можливості

1. **Мульти-джерельне злиття даних (Data Fusion & Correlation)**:
   - **Офіційні тривоги**: моніторинг статусів повітряної тривоги по областях та районах України (`alerts.in.ua`).
   - **ADS-B / Радіодані**: легальні відкриті транспондери авіації та моніторингових бортів (`OpenSky Network`, `airplanes.live`).
   - **Супутникові термоточки**: фіксація вибухів, пожеж та теплових аномалій за даними NASA FIRMS (VIIRS/MODIS).
   - **Метеодані**: напрямок та швидкість вітру на висотах (`Open-Meteo`) для розрахунку зносу БПЛА.
   - **OSINT & Моніторингові канали**: NLP-парсер україномовних та англомовних повідомлень ("Шахеди повз Кременчук курсом на Полтаву", "Ракета на Миколаїв") з географічним довідником понад 100 міст та райцентрів України.
   - **Симулятор повітряного простору**: автономний генератор реалістичних сценаріїв руху цілей для тестування та демонстрації 24/7.

2. **Кінематичний трекінг та фільтрація Калмана (Extended Kalman Filter)**:
   - 2D модель постійної швидкості з оцінкою коваріаційного матриці похибки.
   - Візуалізація конусів невизначеності (Uncertainty Cones) та ліній вектору швидкості.
   - Просторове згладжування шуму GPS та сенсорних вимірювань.

3. **Оцінка персональних загроз та розрахунок часу підльоту (ETA)**:
   - Розрахунок дистанції, азимуту та часу підльоту (ETA в хвилинах) до поточної або обраної точки користувача.
   - Рівні небезпеки: `critical` (підліт < 10 хв у сектор користувача), `high`, `medium`, `low`.
   - Автоматичні рекомендації з безпеки ("Правило двох стін", направлення в укриття).

4. **Telegram Mini App (TMA) — Інтерактивний радар**:
   - 60 FPS Canvas рендеринг поверх MapLibre GL у стилістиці тактичного радара.
   - Кільця дальності (15 км, 30 км, 50 км) навколо позиції користувача.
   - Інтерактивна картка цілі: тип, швидкість (км/год), курс, дистанція, ETA, надійність та час оновлення.
   - Швидкий вибір міст (Київ, Харків, Одеса, Дніпро, Львів тощо) на випадок супутникового спуфінгу або вимкненої геолокації.
   - Захист чутливих даних (Dynamic Jitter) для цивільного режиму.

5. **Telegram-бот**:
   - Команди: `/start`, `/radar`, `/alerts`, `/setlocation`, `/radius`, `/status`, `/report`.
   - Персональні фонові push-сповіщення при вході цілі у радіус контролю.

## 🛠️ Архітектура проекту

```
eye-radar/
├── src/
│   ├── client/                  # Telegram Mini App (React 18, MapLibre GL, Canvas)
│   │   ├── components/          # MapView, ThreatBanner, TargetCard, CitySelector, StatusPanel
│   │   ├── hooks/               # useWsRadar (WebSocket клієнт з дельта-пакетами)
│   │   ├── location/            # Антиспуфінг та узгодження координат
│   │   └── lib/                 # Геодезичні розрахунки (Haversine, Bearing, Destination)
│   ├── server/                  # Серверне ядро (Node.js 20, TypeScript, WebSocket)
│   │   ├── bot/                 # TelegramBot (Telegraf) та диспетчер гео-оповіщень
│   │   ├── core/                # KalmanFilter2D, TrackCorrelator, ThreatEngine, DynamicJitter
│   │   ├── domain/              # Моделі даних та типи
│   │   ├── ingest/              # OSINT NLP-парсер та SDR шлюз
│   │   ├── sources/             # Адаптери: alertsInUa, firmsThermal, openMeteoWind, simulator, ukraineGeo
│   │   └── ws/                  # WebSocket Hub розсилки стиснених пакетів
│   └── test/                    # Автоматичні тести (Vitest: Kalman, Correlator, Threat, OSINT)
├── dist/                        # Зібрані бандли клієнта та сервера
├── Dockerfile                   # Docker контейнер для розгортання
└── docker-compose.yml
```

## 🚦 Швидкий запуск

### 1. Встановлення залежностей
```bash
npm install
```

### 2. Налаштування оточення
Створіть `.env` файл на основі `.env.example`:
```env
BOT_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_telegram_id
HOST=0.0.0.0
PORT=3000
PUBLIC_BASE_URL=http://localhost:3000
WEB_APP_PATH=/app
WS_PATH=/ws
MAP_STYLE_URL=https://demotiles.maplibre.org/style.json
JITTER_RADIUS_KM=15
TRUST_MIN_SCORE=55
```

### 3. Запуск тестів
```bash
npm run test
```

### 4. Збірка
```bash
npm run build
```

### 5. Запуск сервера та клієнта
```bash
# Режим розробки
npm run dev

# Продакшн запуск
npm run start
```

## 🧪 Тестування

Система містить повний набір модульних тестів:
- `src/test/kalman.test.ts`: перевірка згладжування шуму, розрахунку швидкості та конусів невизначеності.
- `src/test/correlator.test.ts`: перевірка дедуплікації та сопоставлення мульти-джерельних спостережень.
- `src/test/threatEngine.test.ts`: тестування векторного аналізу підльоту, розрахунку ETA та рівнів загрози.
- `src/test/osintParser.test.ts`: тестування розпізнавання військових термінів та топонімів України.

## 🔒 Безпека та конфіденційність
- Динамічне просторове згладжування (Dynamic Jitter) гарантує безпеку цивільної аудиторії без розкриття чутливих військових позицій.
- Алгоритм виявлення аномалій перевіряє стрибки координат і захищає від супутникового спуфінгу.
- Усі секрети та токени захищені через environment variables.
